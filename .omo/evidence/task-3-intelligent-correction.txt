  (final_script_or_None, steps). Sources consulted per round in order

  first candidate passing danger.is_dangerous wins the round
  (dangerous candidates declined, consultation continues).

  Acceptance: candidate == current -> STOP stable; candidate in
  visited -> STOP-ABORT (None, steps); else advance. Round with no

  the original failing script is NEVER auto-executed. NO round cap.
  Termination contract stated in the module docstring (visited-set
  kills cycles; sources must be fixed-range or word-count-preserving,
  appending sources forbidden). Compose-local memo dict per

  (source, script) calls distinct).

  composer, no separate short-circuit). None -> rules+ask unchanged.
  Belt-and-suspenders danger check kept before the auto-run.
  _run_learned(): settings.repeat OR non-Nushell -> record(original,
  final) exactly once immediately BEFORE run when >=1 step accepted,
  except a win whose ONLY step was the learned-db exact hit (no
  re-record; mirrors today, preserves test_exact_learned_wins_over_
  guess). Nushell + no-repeat -> learned.close_db(), run,
  returncode==0 -> record else learned.forget(original, final) —

  degraded via the {} fallback (learned.py _init_db).
- thefuck/types.py: CorrectedCommand.run nushell branch stashes
  subprocess.run(...).returncode on the instance (2-line change).
- thefuck/learned.py: forget(original, corrected) — exact inverse of
  record: deletes cmd:original; when token counts match deletes
  word:<orig_parts[0]> and part:<corrected_parts[0]>:<orig_tok> for
  diverged positions (part: keys require the corrected head —
  hence arg 2); delete, not decrement; assembly failures (no cmd:
  key) are a documented NO-OP (word:/part: mappings were validated
  by a prior success of a different command and stand). close_db():
  idempotent, closes shelve if open, sets _db None ({} fallback has
  no close — guarded). atexit now registers the STABLE close_db
  METHOD once (instance flag) instead of the stale-prone
  _db.close object.

Risks / notes
-------------
- Under settings.repeat the child `thefuck --repeat` may hit the
  parent's open shelve: pre-existing, silently degraded via the {}
  fallback (documented, not fixed — per plan).
- forget's word:/part: deletion is exact-inverse-of-record; under
  cross-record interference (a later record overwriting word: for
  the same orig token) the later mapping is deleted too — accepted
  by the plan's literal inverse semantics.
- Nushell outcome gating is new behavior: on success a learned-only
  replay now re-records (count bump), on failure it forgets —
  required for poison self-heal.
